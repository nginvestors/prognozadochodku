# Prognóza dôchodku

Landing page s kontaktným formulárom k dôchodkovej prognóze.

## Spustenie

Otvorte `index.html` v prehliadači alebo nasaďte na Vercel – hlavná stránka je na `/`.

```bash
npm run dev
```

## Ecomail predvyplnenie

V kampani nastav odkaz na formulár s merge tagmi:

`https://TVOJA-DOMENA/?email=*|EMAIL|*&meno=*|NAME|*&priezvisko=*|SURNAME|*#cta`

Stránka predvyplní e-mail a meno. Človek dopíše maximálne telefón.
